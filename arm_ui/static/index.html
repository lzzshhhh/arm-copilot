🔌 端口设置

📼 数据采集设置

          
第四关采集前填一次。数据集名称用「用户名/数据集名」（只存本机不上传的话，用户名随便起）；数量建议 20–50 起步。ACT 训练需要相机——勾选启用后数据会带图像；需要双视角（两个相机互补视角，效果更好）再勾选第二相机

          

            
            
            
            
            
            
          

          
相机编号：USB 相机通常 0 或 1（笔记本自带摄像头常占 0）；采集与评估会自动使用相同的相机组合。建议先用 lerobot-find-cameras 抓预览图确认编号对准工作区

          
        

        

          
🎯 训练设置

          
第四关训练前确认一次。默认 3000 步 / Batch 16 / CPU（lerobot 官方默认 10 万步，CPU 上不现实）。跑通流程验证时可临时填小值（如 2 步，约 3 分钟出 checkpoint）；正式训练建议 2000–5000 步

          

            
            
            
          

          
        

      


      
      

        
🛠️ 舵机 ID 工具（进阶）

        
修复被改乱的舵机编号：先把要改的那一个舵机单独接在控制板上（其余全部断开），扫描确认只有它在线，填上新 ID 点写入。SO-101 关节对照：底座 1 · 肩 2 · 肩转 3 · 肘 4 · 腕转 5 · 夹爪 6
