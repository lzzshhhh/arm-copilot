# 合并 arm_ui 进 arm_copilot：单包重构计划

## Context

项目初期 `arm_ui/` 以"不改动原项目"的外挂方式开发；现在全流程已跑通，用户要求合并为统一项目、重新分类目录并更新 README。原版已由用户另行备份，可在本仓库放心重构。

## 目标结构

```
arm-copilot/
├── arm_copilot/                     # 统一 Python 包
│   ├── __init__.py / __main__.py / cli.py / config.py   # 不动（CLI）
│   ├── agent/ / tools/ / products/                       # 不动（LLM/工具/档案）
│   └── web/                         # ← arm_ui/ 整体迁入
│       ├── __init__.py / __main__.py   # python -m arm_copilot.web
│       ├── app.py / flow.py / executor.py / events.py / approvals.py / servo_tool.py
│       ├── runtime.py               # ← 原 arm_ui/state.py 改名（消除与 state/ 目录同名歧义）
│       ├── static/                  # 前端三件套
│       └── state/                   # 运行时目录（现有 progress.json / run-log.md 物理迁入）
├── tests/                           # ← 合并两处测试（原项目 3 文件 + arm_ui 91 用例）
│   └── conftest.py                  # 新增：统一 sys.path 兜底，删各文件手动 hack
├── docs/
│   └── web-ui.md                    # ← 原 arm_ui/README.md（Web 使用说明 + API 一览）
├── knowledge/                       # 不动（M3 预留）
├── pyproject.toml                   # 依赖合并 + web 入口脚本
└── README.md                        # 重写：单一项目，CLI + Web 双模式
```

## 实施步骤

1. **git mv 迁移**（保留历史）：`arm_ui/*` → `arm_copilot/web/*`；`arm_ui/state.py` → `arm_copilot/web/runtime.py`；`arm_ui/README.md` → `docs/web-ui.md`；`arm_ui/tests/*.py` → `tests/`；删除 `arm_ui/requirements.txt`（内容并入 pyproject）
2. **import 全局替换**：`from arm_ui.` → `from arm_copilot.web.`、`from arm_ui.state import` → `from arm_copilot.web.runtime import`（涉及 app.py / flow.py / executor.py / state.py / __main__.py / 3 个测试文件）；删除 app.py 与测试文件头部的 sys.path hack
3. **运行时状态物理迁移**：`arm_ui/state/{progress.json, run-log.md}` → `arm_copilot/web/state/`（保留 13/13 进度、端口、双视角配置）；.gitignore 规则 `arm_ui/state/` → `arm_copilot/web/state/`
4. **pyproject.toml**：dependencies 增加 `fastapi>=0.110`、`uvicorn>=0.29`；dev 组增加 `httpx>=0.27`；scripts 增加 `arm-copilot-web = "arm_copilot.web.app:main"`（app.py 已有 main() 可直接作 entry point）
5. **docstring 用法更新**：app.py 等头部 `python arm_ui/app.py` → `python -m arm_copilot.web`（或 `arm-copilot-web`）
6. `pip install -e .` 刷新 egg-info
7. **README.md 重写**：合并两个 README——项目简介 / 快速开始（Web 为主、CLI 为辅）/ 安全机制（白名单/确认门/风险分级）/ 新结构树 / 开发与测试（pytest tests/ 一条命令）/ 链接 docs/web-ui.md / 路线图 / License
8. 交接文档.md（本地文件）的启动命令同步更新
9. commit + push（走本机代理 7890）

## 不动的部分

`arm_copilot/{agent,tools,products,cli.py,config.py}`、`knowledge/`、`.env*`、`outputs/`、`logs/`、前端三件套内容本身（仅随目录迁移）。

## 验证

1. `.venv/Scripts/python.exe -m pytest tests/ -q` → 全绿（约 120 用例）
2. 重启服务 `python -m arm_copilot.web` → `curl /api/progress` 返回 13/13、COM11/COM12、双视角配置（证明状态迁移无损）
3. `arm-copilot --version`（CLI 不受影响）、`arm-copilot-web --help`（新入口生效）
4. 浏览器打开 http://127.0.0.1:8000 确认前端正常

## 风险与对策

- egg-info 指向旧路径 → 第 6 步重装覆盖
- 服务在运行 → 全部改完后统一重启
- run-log.md（10MB）迁移 → 本地文件移动，无风险
